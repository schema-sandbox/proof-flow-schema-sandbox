# ProofFlow Schema Sandbox `0.1.0-alpha.3` 发布说明

发布日期：2026-07-30

## 发布定位

本版本从唯一有效代码主干 `0.1.0-alpha.2` 的完整副本继续开发。
Design Package v0.1 作为架构与规范依据，Alpha.1 只作历史参考，没有把
Alpha.1 源文件覆盖或合并到 Alpha.2/Alpha.3。

产品正式名称改为 **ProofFlow Schema Sandbox**，简称 **ProofFlow**。
内部 Python 包名、Alpha.2 API 路径、旧环境变量和 `.smath` 结构继续保留，
以避免破坏兼容性。

## 新能力

### 通用插件主机

- 插件具有发现、显式安装、健康检查、项目启用、禁用和卸载状态。
- 插件版本写入项目 `plugins.lock.json`。
- 禁止静默联网安装；OCI 镜像必须用 digest 固定。
- 插件不能直接写规范事件源，运行结果由服务层转成事件和内容寻址工件。
- `python.local` 保留；新增 `graphviz.local`，本机缺少 Graphviz 时如实报告不可用。
- 成功、失败、超时和截断运行均保留输入、命令、stdout、stderr 和产物。

### 模型会话与交接

- `ModelSession` 明确记录连接器、报告模型、模型家族、角色、可见上下文和完整性。
- `HandoffArtifact` 记录交接输入、拒绝方向、未解决项和接收方影响。
- `ArenaRecipe` 只创建和预览研究流程，不自动启动模型。
- 同模型家族互审会产生相关性警告，不能宣称为独立验证。
- 任何阶段都保留人工闸门和热插入能力。

### 认识增量与历史检索

- 事件新增类型化 `epistemic_delta_type`。
- 旧 Alpha.2 事件在读取时推断类型，不改写原始 JSONL。
- 可检索历史路线、挑战、桥接、死路约束和交接记录。
- 路线相似性端点为重复/近重复路线提供提示，由人决定复用、分叉或继续。

### 生产双画布

- React Flow 研究图展示路线、分支、挑战与桥接关系。
- Excalidraw 用于自由草图；原始场景每次保存为不可变内容寻址工件。
- 机器解释另存为派生工件，不能覆盖作者原图。
- 只有人类 actor 能确认草图元素到研究图对象的映射。
- 历史检索、事件时间线和认识增量可把焦点带回相关研究节点。

## 宪法性约束

- ProofFlow 是实验数学沙箱，不是保证解题产品。
- `UNRESOLVED` 是合法且重要的结果。
- 反对意见容易进入系统，认证关闭仍保持高门槛。
- 人类研究者可以随时介入。
- 可观察研究轨迹、失败路线和原始工件必须保留。
- 不声称访问隐藏思维链。
- 不自动把项目标记为 solved。
