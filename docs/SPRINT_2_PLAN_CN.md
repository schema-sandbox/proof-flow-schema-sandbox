# Sprint 2 计划
## 目标版本：`0.1.0-alpha.3`

建议周期：3–4 周。

## P0-1 插件宿主通用化

- 从硬编码 `python.local` 抽象通用 Plugin Host；
- 完成 plugin manifest 安装、健康检查、启用、版本锁和卸载；
- 增加 OCI 容器运行器；
- 明确网络、文件、CPU、内存和超时权限；
- 首个 Graphviz 插件；
- Python 插件可选依赖环境声明，但禁止静默联网安装。

## P0-2 模型会话与角力配方

- `ModelSession` 和 `HandoffArtifact`；
- 手工网页会话、API 会话和工具会话统一记录；
- Explorer、Builder、Skeptic、Bridge Builder、Simplifier 角色；
- Arena Recipe 创建、运行前预览和人工确认；
- 同模型家族标记为相关审查，不计独立性；
- 默认并发为零，扩容需要人类确认。

## P0-3 认识增量与检索

- 对事件标记 epistemic delta 类型；
- 重复/近重复路线提示；
- 失败、桥接结果、死路和复活条件全文检索；
- 项目级“本轮实际改变了什么”视图；
- 压缩无状态重复文本，但不删除规范事件。

## P1 正式双画布

- 完成 React Flow + Excalidraw 构建；
- 路线/分支/挑战/桥接/工件节点联动；
- 从自由草图建立派生结构节点；
- 原图、作者说明和机器解释分开保存；
- 时间线点击定位到图节点。

## P1 Chat Import 增强

- 粘贴导入；
- 更稳健的 ChatGPT JSON/HTML 适配；
- 导入完整性字段：首回合、回合数、附件状态、缺失状态；
- 用户可编辑候选内容和结构化字段；
- 导入批次 diff 和撤销（通过补偿事件，不改历史）。

## 验收场景

1. 安装并启用 Graphviz 插件，把一组结构化边生成 SVG 工件；
2. 创建一个两角色 Arena Recipe，手工导入两个会话并形成 HandoffArtifact；
3. 在同一项目中检索并复活三周前的死路；
4. 自由草图与路线节点双向引用，但原始图保持不变；
5. 所有新对象导出/导入后事件链完整。
