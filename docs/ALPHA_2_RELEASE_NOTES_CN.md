# SchemaMath `0.1.0-alpha.2` 发布说明

Alpha.2 将 Alpha.1 的路线级纵向切片扩展为可实际保存“研究分化、异议、桥接和工具实验”的本地数学实验环境。

## 本版新增

- `Branch`：路线内的具体参数化或局部尝试；
- `Challenge`：低门槛异议和可执行检验，不自动杀死路线；
- `BridgeResult`：最终陈述中可能消失、但对后续研究有因果价值的中间成果；
- `DeadEndConstraint`：记录已知死路、适用范围和重开条件；
- `ResearchCheckpoint`：主动外化当前目标、假设、增量和未完成义务；
- 路线拆分与合并，且来源关系与原始事件永久保留；
- ChatGPT Markdown、HTML、JSON、纯文本导入预览；
- 只有人类确认后，导入片段才会成为研究节点；
- 项目级、按需启用的 `python.local` 实验插件；
- 成功、失败和超时运行均保存源码、日志、退出状态和输出工件；
- Alpha.2 对象可随 `.smath.zip` 导出、导入并从事件流重建。

## 验证摘要

- 22 项服务与 FastAPI 集成测试通过；
- 15 个运行时 Pydantic Schema 已导出；
- 21 个 JSON Schema 通过 Draft 2020-12 元验证；
- OpenAPI 包含 33 条路径；
- 依赖零 npm 的 `/prototype/` 浏览器界面通过 HTTP 冒烟测试；
- 演示项目包含 27 条事件、5 条路线、2 个分支、2 个挑战、1 个桥接结果、1 条死路约束、1 个检查点和 1 次 Python 工具运行；
- 演示包已在空工作区导入，事件哈希链有效。

完整结果见 `VALIDATION_REPORT.txt`。

## 仍然不是

- 自动证明器或数学正确性裁判；
- 面向不可信代码的安全执行环境；
- 云端多用户产品；
- 能读取闭源模型隐藏思维链的系统；
- 保证解答开放问题的服务。

## 已知限制

- `python.local` 只有进程级隔离，代码仍继承本地用户权限；
- React Flow + Excalidraw 前端仍是脚手架，正式构建未在离线打包环境中完成；
- 没有模型 API 编排、多人协作、远程运行或插件市场；
- 目前只适合本地、单用户、可信代码的研究实验。
