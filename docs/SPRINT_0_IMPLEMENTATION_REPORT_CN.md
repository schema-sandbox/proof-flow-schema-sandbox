# SchemaMath Sprint 0 实施报告
## `0.1.0-alpha.1`

## 1. 本轮目标

把 v0.1 设计基线推进为一个可运行的纵向切片，优先验证：

1. `.smath` 项目是否可以在本地创建、保存、导出和恢复；
2. 所有可观察研究变化能否进入追加式事件流；
3. 路线是否能在不被轻易删除的前提下暂停、复活、桥接和关闭；
4. 原始图片、手稿、代码等是否能按内容哈希保存；
5. 项目上下文能否导出为适合 ChatGPT 网页伴侣模式的 Research Packet；
6. SQLite 索引损坏后能否从事件流重建。

本轮不试图证明数学正确性，也不实现自动解题。

## 2. 已完成的纵向切片

```text
浏览器原型
    ↓ REST
FastAPI Local Core
    ↓
events.jsonl（权威事件源）
    + SQLite（可重建投影）
    + blobs/sha256（原始工件）
    ↓
Research Packet / .smath.zip
```

### 已实现 API

- 创建、列出、读取项目；
- 创建和读取路线；
- 高门槛路线状态变更；
- 人类笔记和通用事件追加；
- 原始工件上传、列表和下载；
- 事件哈希链完整性检查；
- SQLite 投影重建；
- Research Packet 生成；
- `.smath.zip` 导出与导入。

### 已实现浏览器原型

- 项目创建与选择；
- 原始问题展示；
- SVG 路线图；
- 路线状态修改；
- 人类直觉、定义和重定向输入；
- 事件时间线；
- 自由手绘草图；
- 草图与文件保存为内容寻址工件；
- Research Packet 生成、复制；
- 项目完整性检查与导出。

浏览器原型采用原生 HTML/CSS/JavaScript，不依赖 npm 安装，因此可以直接验证交互。正式 React Flow + Excalidraw 前端已有源码脚手架，但在本次离线环境中未下载依赖、未完成构建验证。

## 3. 数据权威边界

| 对象 | 权威来源 | 是否可重建 |
|---|---|---|
| 原始问题 | `project.json` + 初始事件 | 是 |
| 研究历史 | `events/events.jsonl` | 否：它本身是权威源 |
| 路线当前状态 | SQLite 投影 | 是，从事件重放 |
| 原始工件 | `blobs/sha256/` | 需由哈希与元数据核验 |
| 自由画布 | `canvas/main.excalidraw` | 当前独立文件保存 |
| 插件版本 | `plugins/plugins.lock.json` | 当前为空清单 |
| 导出报告 | 派生工件 | 是 |

## 4. 路线关闭约束

`CERTIFIED_CLOSED` 不是普通按钮状态。Alpha.1 后端要求：

- 人类 actor，或显式的人类确认；
- 至少一个关闭证据引用；
- 从当前状态到关闭状态必须符合状态机。

这只是防止轻率关闭的最低实现，并不自动判断证据是否数学上充分。

## 5. 事件完整性

每条事件包含：

- `previous_event_hash`；
- 当前事件规范 JSON 的 SHA-256；
- actor、时间、路线、工件引用和认识变化说明。

当前锁机制只保证单进程内的追加安全。跨进程文件锁和崩溃恢复属于下一阶段任务。

## 6. 已完成验证

- Python 单元与 API 集成测试：5 项通过；
- 10 个 JSON Schema 文件通过 Draft 2020-12 schema 自检；
- Python 源码通过 `compileall`；
- 演示项目可以创建并导出 `.smath.zip`；
- 删除 SQLite 后，路线状态可以从事件流重建；
- 事件哈希链可校验；
- 正式关闭在没有人类和证据时被拒绝。

## 7. 未完成和已知限制

1. React/Vite 前端尚未在本环境构建；
2. Excalidraw 文件尚未与浏览器原型的 canvas 实时同步；
3. 插件管理器与 runner 尚未实现；
4. ChatGPT 只支持 Research Packet 手工伴侣流程；
5. 尚无模型会话导入解析器；
6. 尚无分支、BridgeResult、DeadEndConstraint 独立数据库对象；
7. 事件源尚未使用跨进程锁或事务日志；
8. 导入包只做路径安全和 manifest 校验，尚未逐文件核对 SHA-256；
9. 没有数学正确性判定；
10. 服务只适合绑定 `127.0.0.1`，不能直接暴露到公网。

## 8. 下一实现阶段

Sprint 1 应围绕三个用户闭环展开：

### 闭环 A：可恢复研究路线

- Branch 对象；
- Challenge、BridgeResult、DeadEndConstraint；
- 路线合并和分裂；
- 研究检查点；
- 路线级回放和恢复。

### 闭环 B：ChatGPT 网页伴侣

- 选定节点组装 Research Packet；
- Markdown/HTML/JSON 会话导入；
- 将导入内容拆成候选、异议、障碍和下一步建议；
- 保留原始输出与派生解释的双层结构。

### 闭环 C：第一个按需插件

- 插件安装确认；
- Python venv runner；
- 输入、输出、日志、退出码和资源限制；
- Graphviz 路线可视化插件；
- 失败运行完整保存。

## 9. 发布判断

Alpha.1 可以作为内部开发基线和开源仓库初始提交，但还不适合面向普通用户宣传。建议在 Sprint 1 完成后发布第一个公开开发预览版。
