# ProofFlow React Web

Production React Flow and Excalidraw dual-canvas application for
`0.1.0-alpha.4`.

The route canvas links routes, branches, challenges and bridge results. The
free canvas persists each save as a new content-addressed artifact and event;
it never overwrites an earlier drawing. Timeline and epistemic-delta entries
can focus linked graph nodes.

```bash
npm install
npm run build
npm run dev
```

This remains a local experimental mathematics sandbox. The interface does not
promise a solution, auto-close routes or expose hidden model reasoning.
